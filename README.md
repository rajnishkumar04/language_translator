# NeuralTranslate | Full-Stack AI Linguistic Engine

**Version 3.0.0 (Full-Stack Architecture)**

NeuralTranslate is now a robust full-stack application with a dedicated Node.js backend and a high-performance Cyber-Neural frontend.

## 🏗 Architecture
- **Frontend**: Cyber-Future interface (HTML/CSS/JS) served on port `62780`.
- **Backend**: Node.js Express server running on port `5000`. It handles all neural processing requests and proxies them to the MyMemory translation layer.

## 🚀 How to Run
To start both the frontend and backend concurrently, run the following command in the root directory:
```bash
npm run dev
```

## 🛠 Project Structure
- `/frontend`: High-fidelity UI, CSS animations, and client-side logic.
- `/backend`: Express server, API endpoints, and middleware.
- `package.json`: Root configuration for managing both systems.

## ⚡ Features
- **Neural Proxy**: Backend handling of API requests for better security and stability.
- **Cyber-Neural UI**: Immersive dark-mode theme with grid and scanline effects.
- **Voice Talk**: Full Speech-to-Text and Text-to-Speech support.
- **Auto-Sync**: Real-time translation as you type.
- **Terminal History**: On-screen log of all processed data.
