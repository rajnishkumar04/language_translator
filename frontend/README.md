# NeuralTranslate | Next-Gen Linguistic Engine

**Version 2.0.0 (Cyber-Overhaul)**

A high-tech, AI-centric translation suite designed for professionals. This version features a complete redesign focused on a futuristic "Neural" aesthetic with real-time processing capabilities.

## ⚡ New in v2.0
- **Neural Processing Theme**: Deep black background with neon cyan/purple accents and animated grid floor.
- **Typewriter Rendering**: Translations appear character-by-character, simulating an AI data stream.
- **Auto-Sync**: Real-time translation as you type (with advanced debouncing).
- **Terminal Logs**: A persistent command-line style history of your translations.
- **Glitch UI**: High-fidelity micro-interactions and glitch effects on interactive elements.
- **Audio Stream**: Integrated text-to-speech for Hindi, English, and German.

## 🛠 Tech Stack
- **Engine**: ES6+ JavaScript with Fetch API.
- **Interface**: HTML5 Semantic markup.
- **Styling**: CSS3 with CSS Variables, Perspective transforms, and Keyframe animations.
- **API**: MyMemory Neural Translation Layer.

## 🚀 Deployment
Open `index.html` in any browser or run:
```bash
npx serve .
```
